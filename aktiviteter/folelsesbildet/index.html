Følelsesbildet
Utforsk ett bilde sammen med klassen – hvilke følelser kan det uttrykke?

Velg ett bilde til klassen

📋 Lærerveiledning

Formål

Aktiviteten trener elevene i å legge merke til følelsesuttrykk, sette ord på følelser, forstå sammenhengen mellom følelser, kropp og situasjon, og reflektere over hvordan andres følelser påvirker dem selv.

Slik gjennomføres den

  1. Vis bildet uten forklaring i 10–15 sekunder.
  2. Start med: «Hva legger dere merke til?»
  3. Be elevene foreslå følelser og begrunne dem med konkrete spor i bildet.
  4. Utforsk hvordan følelsen kan se ut, høres ut og kjennes.
  5. Knytt følelsen til mulige situasjoner.
  6. Avslutt med setningsstarteren: «Når jeg møter denne følelsen hos andre …»

Oppmuntre til formuleringer som «Jeg tror … fordi …». Elevene skal ikke måtte dele egne erfaringer – de kan snakke om personen eller figuren i bildet.

Faglig begrunnelse

  • Emosjonell kompetanse omfatter blant annet emosjonell kunnskap, emosjonelt uttrykk og regulering.
  • Aktiviteten trener særlig emosjonsforståelse og sosial bevissthet.
  • Å sette ord på følelser og forstå følelsers uttrykk, årsaker og virkninger henger sammen med sosial kompetanse.
  • Læreren bør behandle elevenes tolkninger som mulige forklaringer og be dem begrunne dem med observasjoner.
  • Følelsestolkning påvirkes av kontekst, kultur og den som observerer.
