# Statistikkbyggeren

En statisk HTML/CSS/JS-prototype for et statistikkspill der spilleren konstruerer datasett som passer gitte krav.

## Innhold
- 6 kampanjenivåer
- 10 faste oppgaver per nivå
- Gjennomsnitt, median, typetall og variasjonsbredde
- Live-validering
- Constraints
- Låste tall
- Hint
- Oppgaver med krav om flere løsninger
- Lokal lagring av progresjon

## Kjøring
Åpne `index.html` direkte i nettleseren, eller server mappen med en enkel lokal webserver.
